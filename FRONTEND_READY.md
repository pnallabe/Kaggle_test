## 🚀 QUICK START

### Step 1: Navigate to Frontend
```bash
cd frontend
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Configure Environment
```bash
cp .env.example .env.local
# Edit VITE_API_URL to your backend URL
```

### Step 4: Start Development
```bash
npm run dev
```

### Step 5: Open Browser
```
http://localhost:3000
```
